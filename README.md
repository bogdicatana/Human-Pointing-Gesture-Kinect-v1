# Human Pointing Gesture Recognition

## Project Description
This project was made as a proof of concept way of detecting pointing gestures using the Kinect camera of the Xbox 360 and mathematical equations.
Keep in mind the example experiment setup below has hard coded "objects" to point at. They are just representative of different directions and angles.
The intended use for this project was to help robots take commands by pointing to help the elderly outside of nursing homes.

## Installation
You will need python 2.7 32 bit (I know it is old but so is the Kinect camera) and an Xbox 360 camera. As well as the Kinect SDK from Microsoft.
You will also need the python libraries pykinect, pygame, numpy.
